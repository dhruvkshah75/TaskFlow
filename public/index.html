Before you run it

A few useful details.

A little context before you put your first task in motion.

What kind of tasks can I run?

Python files with a handler(payload) function. Synchronous and asynchronous handlers are supported. Match the task title to the Python filename without its extension.

How does worker scaling work?

KEDA monitors Redis queue depth and adjusts the Kubernetes worker deployment from 2 to 20 pods. The scaling controls above illustrate the concept; they do not control a real cluster.

Do code changes require rebuilding workers?

No. TaskFlow supports dynamic Python uploads. Workers load the uploaded task code through shared storage without rebuilding the worker image.

What do I need to run it locally?

Docker with its daemon running, Minikube, and kubectl. Follow the repository README for prerequisites and local deployment instructions.

Where does task status live?

PostgreSQL stores task history and status. Redis handles the message queues, while workers execute the Python handlers.

Can I inspect and change the source?

Yes. TaskFlow is open source under the MIT license. Explore the repository, run it on your own infrastructure, and adapt the code to your needs.
